What's different in the DaisyUI version
More rounded
Border radius increases from 12px → 16px (rounded-2xl). Slightly more "consumer product" feel.
Card shadows
Cards get a subtle shadow (shadow-sm) instead of just borders. Adds depth.
Inputs more prominent
DaisyUI's input-bordered has a visible border + more padding. Easier to see input fields.
Evidence pills brighter
DaisyUI's badge-success/info/warning are saturated. More obvious at a glance.
Looks more "designed"
Header in a navbar component, divider between sections. Recognizable DaisyUI patterns.
What stays the same
Dark green primary, all content/copy, Korean i18n, image upload, all functionality.
